### Techniques marquantes
- **Cloud** : SSRF → IMDS → assume-role → objet privé (série imds) ; JWT **alg:none** (série oidc) ;
  secret oublié dans la zone publique → montée de privilège (série prefix).
- **Crypto** : attaque par **faute** sur AES (sokode) ; **padding oracle** Vaudenay sur protocole
  binaire maison, parallélisé sur 12 connexions TLS (padding-oracle-lite) ; prédiction de PRNG
  (MT19937 untempered, LFSR / Berlekamp-Massey).
- **Web** : confusion d'algo **RS256→HS256** (cms-jwtconf, togbi) ; SQLi second ordre + bypass WAF
  (anie, shadow-catalog) ; **logique métier** (bitvault : rebate / volume non décrémentés) ;
  RCE via transport git **`ext::`** (hookrelay).
- **Reverse** : désaccord **vérificateur eBPF vs CPU** → fuite mémoire hors des 64 cases (ebpf-mirage).
